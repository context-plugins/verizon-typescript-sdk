
# Hpl Bullseye Enable

A flag that shows if Hyper Precise is enabled (true) or disabled (false).

## Structure

`HplBullseyeEnable`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `bullseyeEnable` | `boolean \| undefined` | Optional | - |

## Example

```ts
import { HplBullseyeEnable } from 'verizonlib';

const hplBullseyeEnable: HplBullseyeEnable = {
  bullseyeEnable: true,
};
```
