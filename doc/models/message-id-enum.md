
# Message Id Enum

The type of ITIS message (typically 1 for DENM).

## Enumeration

`MessageIdEnum`

## Fields

| Name | Description |
|  --- | --- |
| `Enum1` | Value 1 — identifies the message as a DENM |

## Example

```ts
import { MessageIdEnum } from 'verizonlib';

const messageId = MessageIdEnum.Enum1;
```
